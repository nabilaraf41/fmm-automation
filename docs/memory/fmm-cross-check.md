Before posting, planning or presenting any FC Mobile card, event or player list, cross-check it against a second
independent source (RenderZ + fcmobileforum, or creators' YouTube titles). Hold anything only one source shows.

**Why:** user asked explicitly (Oct 2026) after TOTW27 appeared on fcmobileforum but not on RenderZ.
**How to apply:** the pipeline enforces it (slots.confirmed_only, content/featured.json confirmed_programs /
hold_programs); when doing anything by hand, verify first and say what was confirmed. See [[fmm-automation-setup]].
